#  DY67 – Terraform Azure VM Lab

short draft to keep track of what was used in the Terraform configuration and where to verify it in the official documentation.
It is organized by main.tf, variables.tf and outputs.tf.

---

# main.tf

## Provider

AzureRM provider configuration for Azure resources.
define provider source and version.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs

---

## Resource Group

Creates the resource group that contains all deployed components.
Used for logical grouping and tagging.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/resource_group

---

## Virtual Network

Defines the virtual network and address space for the environment.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/virtual_network

---

## Subnet

Defines the subnet where the VM network interface is placed.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/subnet

---

## Network Security Group

Defines inbound security rules such as HTTP and RDP and restricts source IPs.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/network_security_group

---

## Network Interface

Creates the NIC and private IP configuration for the VM.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/network_interface

---

## NSG Association

Associates the NSG to the NIC so rules apply to the VM.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/network_interface_security_group_association

---

## Windows Virtual Machine

Defines the Windows Server VM, size, admin credentials, OS disk and image reference.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/windows_virtual_machine

---

## Managed Disk

Creates the additional HDD data disk (50 GB).
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/managed_disk

---

## Data Disk Attachment

Attaches the managed disk to the VM.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/virtual_machine_data_disk_attachment

---

## Virtual Machine Extension

Runs PowerShell scripts for IIS installation and site setup.
https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs/resources/virtual_machine_extension

---

# variables.tf

Defines configurable inputs like location, credentials, IP restriction and tags.
https://developer.hashicorp.com/terraform/language/values/variables

---

# outputs.tf

Displays values after deployment such as private IP for verification.
https://developer.hashicorp.com/terraform/language/values/outputs
